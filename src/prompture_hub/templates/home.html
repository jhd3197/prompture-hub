Get started — issue your first scoped key

Hub keys are how untrusted apps call your provider LLMs without seeing the real credentials. Each one whitelists models and caps spend.

curl example POST /admin/keys 
curl -X POST http://localhost:1984/admin/keys \
  -H "Authorization: Bearer $HUB_ADMIN_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "name": "my-first-app",
    "allowed_models": ["ollama/llama3.1:8b"],
    "daily_spend_cap_usd": 1.0
  }'

Don't have $HUB_ADMIN_TOKEN? Set it in .env and restart the hub.
